# QOP Hope Foundation website

Website of the Queen of Peace Hope Foundation (QOP Hope Foundation), Isiolo County, Kenya. Plain HTML and CSS, hosted on GitHub Pages. Domain: qophope.org (once connected).

- `index.html`: the whole site (Home, About, Our work, Impact, Partners, Get involved, Give).
- `img/`: photos by Cliffe Wasike for the Foundation, illustrations, and county map data (geoBoundaries, public domain).

Rules: no child's name, face, school or village. Photos only with permission. Money never goes through the website.
